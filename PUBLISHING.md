# Publishing Context Prewarm

1. Create a public repository named context-prewarm under your account.
2. If it contains an initial README, replace that with the project's README.
3. Upload all project files, including hidden .github and .gitignore entries.
4. Verify that skills/context-prewarm/SKILL.md is visible in the default branch.
5. Enable GitHub Actions if prompted and check the unit tests.
6. Add repository topics such as agent-skills, codex, prompt-caching, context-engineering.
7. Optionally create a v0.1.0 GitHub release after verification.

For local Git, clone the already-initialized repository and copy project files into the clone before committing.
